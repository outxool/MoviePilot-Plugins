# TG 115自动转存

MoviePilot v2 插件：低频增量读取公开 Telegram 频道页面，提取消息或 Telegraph 页面中的 115 分享链接，匹配 MoviePilot 活动订阅后，直接使用 `p115client` 转存到手动配置的目录。

## 路径配置

- CloudDrive2 前缀：`/115open`
- 转存目标完整路径：`/115open/最近接收/TG`
- 插件自动换算出的 115 内部目录：`/最近接收/TG`

## 桥接

转存成功后发送 MoviePilot 内部事件：

```python
{"action": "p115bridge_tg_transfer_success", "source": "Tg115AutoTransfer"}
```

事件不携带精确路径。升级后的 `115整理入队桥接` 使用自己的 TG 入队目录配置，将固定根目录交给 MoviePilot 原生整理队列。

## 首次运行

默认只建立各频道当前最大消息 ID，不回补历史，避免首次安装自动转存大量旧资源。需要测试时先开启“仅日志演练”，也可临时开启“首次回补当前页”。

## 去重与重试

- 演练模式不会写入已转存记录，关闭演练后仍可真实转存。
- 失败消息不会写入内容哈希，只要该消息仍在公开频道当前页，下次扫描会重试。
- 去重键包含分享码和消息内容哈希；频道编辑原消息或重新发布同一链接时会再次触发。
- v0.1.0 暂未主动递归复查长期不变的分享文件夹；若频道不编辑消息也不重新发布，同一分享目录后续静默增加文件不会自动感知。
