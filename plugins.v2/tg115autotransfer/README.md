# TG 115自动转存

版本：0.4.2

## v0.4.2 更新说明

本版重点优化交互和追更自动化：

1. 页面按钮改为“图标 + 中文功能名 + 用途说明”，不再只有图标。
2. 定时设置改为 MoviePilot 标准 `VCronField` 时间选择器，不需要手写 `*/15 * * * *`。
3. 新增 MoviePilot 订阅后，默认延迟 30 秒自动搜索该订阅的 TG 资源。
4. 原“历史回填”界面文案改为“收集 TG 旧资源”，说明清楚：它只是把 TG 频道以前发过的 115 分享保存到本地历史资源库，默认不直接转存。
5. 新增电视剧追更搜索总开关，默认关闭。
6. 新增手动更新时间识别，支持“每日21:30更新”“每晚21:30两集连播”“每周一至周五21:30更新”等文本。
7. 新增全网自动查询更新时间开关，默认关闭。
8. 追更搜索默认在更新时间后 35 分钟执行，只搜索对应单剧，并继续遵守 115 限速、缺失集和媒体库检查规则。

## 主要功能

- 扫描公开 TG 频道里的 115 分享链接。
- 将 TG 资源保存到本地 SQLite 历史资源库。
- 根据 MoviePilot 当前订阅匹配资源。
- 根据缺失集、媒体库状态、低质关键词判断是否应自动转存。
- 对 115 转存做单轮上限、单订阅上限、转存间隔和限流冷却保护。
- 转存成功后可通知 115 整理桥接。
- 新增订阅后可自动延迟搜索。
- 可选电视剧追更：按更新时间后指定分钟单剧搜索。

## “收集 TG 旧资源”是什么意思？

TG 频道可能早就发过某部剧或电影。如果插件只从现在开始扫描，以后你新增老剧订阅时就匹配不到以前发过的资源。

“收集 TG 旧资源”的作用是：慢慢往前翻 TG 频道以前的公开消息，把里面的 115 分享保存到插件本地历史资源库。这样以后新增订阅时，插件可以从旧资源里找，不用等 TG 频道重新发布。

默认情况下，这个操作只是入库，不直接转存。

## 建议首次使用方式

1. 配置公开 TG 频道。
2. 填写 115 Cookie。
3. 打开“仅日志演练”。
4. 点击“收集 TG 旧资源”，先建立历史资源库。
5. 点击“重新匹配历史库”观察日志。
6. 确认不会乱匹配、不会重复转存后，再关闭“仅日志演练”。

## 追更功能建议

追更总开关默认关闭。需要时再开启。

全网自动查询更新时间默认关闭。开启后插件会尝试从公开网页搜索更新时间，但平台排播、会员更新、临时停播都可能导致信息不准，因此建议把它当辅助功能，必要时手动确认。

默认设置：

- 电视剧追更搜索：关闭
- 自动上网查询更新时间：关闭
- 更新时间后延迟搜索：35 分钟
- 单剧每次最多转存：1 条
- 每部剧每天最多触发：2 次

## 安装提醒

本插件包含多个文件，不要只替换 `__init__.py`。请完整替换 `tg115autotransfer` 目录。
